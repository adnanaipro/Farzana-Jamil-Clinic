Cookie policy

This static demo sets no analytics, advertising, marketing, or third-party cookies. It collects no patient, booking, clinic, or marketing data.

One local preference

If you choose “Got it” on the homepage information bar, the browser stores the only local preference: the acknowledgement key nexacare_demo_privacy_v1 with the value acknowledged. It is used only to keep that information bar dismissed on this device.

Reset this local acknowledgement

Selecting the button below removes only that local preference. The current implementation then confirms that the information bar will appear when you return to the homepage. If browser storage is blocked, the site remains usable and no preference is saved.
